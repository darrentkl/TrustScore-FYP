# Trust Score Engine for Gen Z Credit Simulation

## Requirements
- Python and Node.js
- Android Studio with an Android emulator
- Supabase project credentials and an OpenAI API key

## Run the backend

Open a terminal in the `backend` folder:

```bash
pip install -r requirements.txt
```

Copy `backend/.env.example` to `backend/.env` and fill in your credentials. Then run:

```bash
python main.py
```

## Run the frontend

Start an Android emulator. Open another terminal in the `frontend` folder and run:

```bash
npm install
npx expo start --android
```
